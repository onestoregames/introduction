최근 3개월 안에 그 게임에 결제했거나 받은 이용자에게는 보이지 않습니다.

Your items are not shown to users who, within the last 3 months, paid in your game or received an item from it.

不会向最近3个月内在该游戏中付费过或领取过道具的用户展示。

直近3か月以内に、そのゲームで課金した、またはアイテムを受け取ったユーザーには表示されません。

이용자 1명은 어떤 기준인가요?

What counts as one user?

“1名用户”以什么为准？

1人のユーザーとは何を基準にしますか？

원스토어 계정(회원) 1개입니다. 아이템은 구독한 계정에 지급됩니다.

One ONEstore account (member). Items are given to the account that subscribed.

以1个 ONEstore 账号（会员）为准。道具发放给订阅的账号。

ONEstore のアカウント（会員）1つです。アイテムは加入したアカウントに付与されます。

계정을 여러 개 만들면 더 받을 수 있나요?

Can a user get more items by creating several accounts?

创建多个账号就能领取更多吗？

アカウントを複数作ると、より多く受け取れますか？

계정마다 구독료 4,900원이 들고, 등급은 전월 레벨업 패스 결제 실적으로 정해집니다. 새 계정은 실버에 머무르므로 실익이 없습니다.

Each account costs ₩4,900 for the subscription, and the tier is set by the previous month's Level-up Pass payment record. A new account stays at Silver, so there is no real gain.

每个账号都需支付订阅费₩4,900，等级由上月升级通行证的支付记录决定。新账号只会停留在白银等级，因此没有实际收益。

アカウントごとに購読料₩4,900がかかり、ランクは前月のレベルアップパスの決済実績で決まります。新しいアカウントはシルバーにとどまるため、実益はありません。

개발이 많이 필요한가요?

Does it take much development work?

需要大量开发工作吗？

多くの開発が必要ですか？

IAP SDK v21이 있으면 인앱 상품 등록(최소 100원)과 '구매 확인 → 지급 → 소비' 처리만 하면 됩니다.

If you have IAP SDK v21, you only need to register in-app products (minimum ₩100) and handle "check purchase → deliver → consume".

如已接入 IAP SDK v21，只需登记应用内商品（最低₩100），并完成“购买确认 → 发放 → 消耗”处理即可。

IAP SDK v21 があれば、アプリ内商品の登録（最低₩100）と「購入確認 → 付与 → 消費」の処理を行うだけです。

이용자 문의는 누가 받나요?

Who handles user inquiries?

用户咨询由谁受理？

ユーザーからのお問い合わせは誰が対応しますか？

게임에 아이템이 안 들어왔다는 문의는 개발사, 받기 화면·구독 문의는 원스토어가 받습니다.

The game company handles inquiries about an item not arriving in the game. ONEstore handles inquiries about the claim screen and the subscription.

关于道具未发放到游戏内的咨询由游戏公司受理，关于领取页面和订阅的咨询由 ONEstore 受理。

ゲームにアイテムが届かないというお問い合わせはゲーム会社が、受け取り画面・サブスクリプションに関するお問い合わせは ONEstore が対応します。

몇 개까지 나가나요?

How many items are given out?

最多发放多少个？

何個まで配布されますか？

개발사가 신청할 때 지급 수량을 직접 정합니다. 다 나가면 '소진'으로 표시됩니다.

The game company sets the quantity itself when it applies. When all of them have been given out, the item is marked "All claimed".

游戏公司在申请时自行设定发放数量。全部发完后显示为“已领完”。

ゲーム会社が申請時に付与数量を自ら決めます。すべて配布されると「配布終了」と表示されます。

어떤 게임이 참여하나요?

Which games take part?

哪些游戏参与？

どのゲームが参加しますか？

원스토어가 입점 게임과 출시 예정 게임 중에서 선정해 순차적으로 늘립니다.

ONEstore selects from games launched on ONEstore and games scheduled to launch, and adds more in stages.

由 ONEstore 从已入驻游戏和即将上线的游戏中选定，并逐步增加。

ONEstore が配信中のゲームとリリース予定のゲームの中から選定し、順次増やしていきます。

최소 가치는 어떤 금액 기준인가요?

What amount is the minimum value based on?

最低价值以什么金额为准？

最低価値は何の金額が基準ですか？

패키지 구성 아이템의 합산이 아니라 실제 인앱 판매가 기준입니다.

It is based on the actual in-app selling price, not the sum of the items in a package.

以实际的应用内销售价为准，而不是礼包内道具的合计。

パッケージを構成するアイテムの合算ではなく、実際のアプリ内販売価格が基準です。

이용자가 다른 등급 상품을 고를 수 있나요?

Can a user choose a product from another tier?

用户可以选择其他等级的商品吗？

ユーザーは他のランクの商品を選べますか？

아니요. 지난달 결제로 정해진 본인 등급의 상품만 받고, 등급마다 상품은 1개만 등록합니다.

No. Users receive only the product of their own tier, set by last month's payments, and only 1 product is registered per tier.

不可以。用户只能领取由上月付费确定的本人等级商品，每个等级只登记1个商品。

いいえ。前月の決済で決まった自分のランクの商品だけを受け取り、ランクごとに商品は1つだけ登録します。

등급은 어떤 결제로 정해지나요?

Which payments determine the tier?

等级由哪些付费确定？

ランクはどの決済で決まりますか？

쿠폰 등 할인분을 제외한 실결제 금액 기준이며, 지정된 결제 수단으로 결제한 금액만 집계합니다.

The tier is based on the amount actually paid, excluding discounts such as coupons, and only payments made with designated payment methods are counted.

以扣除优惠券等折扣后的实际付费金额为准，仅统计通过指定支付方式支付的金额。

クーポンなどの割引分を除いた実際の決済金額が基準で、指定された決済手段での決済額のみ集計します。

받은 이용자는 언제 다시 받을 수 있나요?

When can a user receive from the same game again?

领取过的用户何时可以再次领取？

受け取ったユーザーはいつ再び受け取れますか？

이번 회차와 직전 3개 회차에 받은 게임은 노출되지 않습니다. 예: 12월 회차에는 9·10·11월 회차에 받은 게임이 제외됩니다.

Games a user received from in this round or the previous 3 rounds are not shown. Example: in the December round, games received in the September, October and November rounds are excluded.

本期和之前3期领取过的游戏不会展示。例如：12月这一期会排除9月、10月、11月领取过的游戏。

今回と直前3回の回で受け取ったゲームは表示されません。例：12月の回では、9・10・11月の回で受け取ったゲームが除外されます。

IAP SDK v16 이하도 참여할 수 있나요?

Can games on IAP SDK v16 or below take part?

IAP SDK v16 及以下版本可以参与吗？

IAP SDK v16 以下でも参加できますか？

참여가 어렵습니다. v16 이하는 v21로의 업데이트가 지원되지 않으며, v17 이상은 앱 업데이트로 v21을 적용할 수 있습니다.

It is difficult. Updating from v16 or below to v21 is not supported, while v17 or above can apply v21 through an app update.

比较困难。v16 及以下不支持升级到 v21，v17 及以上可通过应用更新接入 v21。

参加は難しいです。v16 以下は v21 へのアップデートに対応しておらず、v17 以上はアプリのアップデートで v21 を適用できます。

새로 만든 상품도 바로 쓸 수 있나요?

Can newly created products be used right away?

新创建的商品可以直接使用吗？

新しく作った商品もすぐに使えますか？

이미 판매 중인 상품은 추가 배포 없이 반영됩니다. 게임패스용으로 새로 만든 상품은 게임이 지급할 수 있도록 첫 지급 전까지 업데이트가 필요합니다.

Products already on sale are reflected without an extra release. Products newly created for Game Pass need an update before the first delivery so that the game can deliver them.

已在销售的商品无需额外发布即可生效。为 Game Pass 新创建的商品，需在首次发放前完成更新，游戏才能发放。

すでに販売中の商品は、追加配布なしで反映されます。Game Pass 用に新しく作った商品は、ゲームが付与できるよう、最初の付与までにアップデートが必要です。

게임패스 지급 건은 어떻게 구분하나요?

How are Game Pass deliveries told apart?

如何区分 Game Pass 的发放记录？

Game Pass の付与分はどう区別しますか？

별도 구분 필드는 없습니다. 게임패스용으로 지정한 상품 ID로 구분하며, 중복 지급은 purchaseToken으로 막습니다. 원스토어 회원 식별자는 제공하지 않습니다.

There is no separate field. They are told apart by the product ID designated for Game Pass, and duplicate delivery is prevented with the purchaseToken. The ONEstore member identifier is not provided.

没有单独的区分字段，以指定为 Game Pass 的商品 ID 区分，重复发放通过 purchaseToken 防止。不提供 ONEstore 会员标识符。

区別用の専用フィールドはありません。Game Pass 用に指定した商品 ID で区別し、重複付与は purchaseToken で防ぎます。ONEstore の会員識別子は提供しません。

테스트는 어떻게 하나요?

How do we test?

如何测试？

テストはどのように行いますか？

원스토어 IAP v21 테스트 가이드로 구매 조회·지급·소비 처리가 정상 동작하는지 확인합니다. 이후 상품 등록부터 수령까지 전체 프로세스는 원스토어에서 일괄 확인합니다.

Use the ONEstore IAP v21 test guide to check that purchase lookup, delivery and consumption work correctly. ONEstore then checks the whole process, from product registration to receipt, in one go.

通过 ONEstore IAP v21 测试指南，确认购买查询、发放和消耗处理是否正常运行。之后，从商品登记到领取的整个流程由 ONEstore 统一确认。

ONEstore IAP v21 のテストガイドで、購入照会・付与・消費処理が正常に動作するか確認します。その後、商品登録から受け取りまでの全プロセスは ONEstore が一括で確認します。
